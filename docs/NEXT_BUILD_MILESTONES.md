# Tidelight next build program

## Stage 1 — Brand system and responsive parity
- Keep desktop navigation meaning on mobile with the same branded rail.
- Standardize Tidelight navy, ocean teal, aqua, amber and typography tokens.
- Replace generic icon treatment with the Tidelight tide/light mark.
- Add branded glow, focus, active-state and surface effects.
- Verify all three theme modes and 320px–1440px layouts.

## Stage 2 — Trust and account readiness
- Apply the encrypted Bitget connection migration in Supabase.
- Configure server-only credential encryption.
- Complete Google OAuth display-name/consent-screen verification.
- Verify email OTP delivery, redirect URLs, and rate limits.
- Finish passkey registration/readiness and security-event review.

## Stage 3 — Bitget execution desk
- Demo-key connection and balance verification.
- Reality/rToken instrument validation and precision handling.
- Manual demo order review, confirmation and audit.
- Live order enablement only after MFA, key verification and risk acknowledgement.
- Order history, cancel/retry semantics, idempotency and provider error mapping.

## Stage 4 — Agentic trading v2
- Keep Nightwatch paper-first by default.
- Add configurable signal policies, exposure limits and cool-downs.
- Add explicit “paper / Bitget demo / Bitget live” execution modes.
- Add decision timeline: event → evidence → signal → risk gate → order → result.
- Add kill switch, daily loss cap, maximum open exposure and stale-data lock.

## Stage 5 — Quick intelligence
- Token/company lookup from a name, ticker or rToken.
- Multi-source collection: issuer/SEC, news, RSS, community and social links.
- Duplicate clustering, source quality, contradiction detection and freshness.
- Beginner read plus Pro evidence view.
- “What to verify next” instead of unqualified trade calls.

## Stage 6 — Institutional proof
- Longer walk-forward strategy tests across rTokens and crypto.
- Fees, slippage, latency and out-of-sample reporting.
- Exportable decision and execution audit trail.
- Demo mode with seeded data and deterministic judge walkthrough.
- Security, accessibility, mobile and performance review.

## Stage 7 — Submission polish
- Branded README and architecture narrative.
- Three-track demo: Alpha Factory, Agentic Trading and AI Trading Desk.
- 3-minute judge path, screenshots, metrics and limitations.
- Public preview, health checks and final deployment freeze.
