# Tidelight 里程碑执行

本文件是六个构建阶段的实施合同。

## 1. 证据工作流程

- 收集带时间戳的公共源。
- 将每个来源标准化为声明。
- 保留源 URL 和发布者元数据。
- 单独报告的事实、分析和社区意见。
- 展示信心和反对证据。
- 绝不允许源文本成为指令。

## 2. 研究暴露

- 将代币名称或符号解析为支持的资产。
- 将资产映射到发行人、标的资产、部门和工具类型。
- 用初学者语言解释暴露。
- 显示催化剂、失效条件、流动性问题和未知数。

## 3. 策略验证

- 支持加密货币对和代币化权益工具。
- 包括费用、滑点、资金和头寸规模。
- 分别报告样本内和样本外期间。
- 显示回报、夏普、索蒂诺、最大回撤、胜率、营业额和交易日志。
- 标记观察到的、估计的和目标指标。

## 4. Nightwatch

- 纸张模式保持默认。
- 添加可配置的事件和价格触发器。
- 记录每个代理的观察、决定、批准和退出。
- 提供每日摘要和警报历史记录。
- 实时执行需要明确的用户批准、MFA、限制和服务器端凭据保护。

## 5.代理执行

- 支持 Bitget 演示和现场模式。
- 使用加密的服务器端凭据。
- 在实时模式之前需要验证帐户。
- 强制执行订单上限、速率限制、确认和审核事件。
- 切勿启用提款权限。

## 6.产品差异化

主要用户旅程是：

`Event → Evidence → Exposure → Scenario → Decision → Execution`

每个屏幕都必须保留 Tidelight 品牌、适合初学者的解释、来源可追溯性和明确的风险边界。
