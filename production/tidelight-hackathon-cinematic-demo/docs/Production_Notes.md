PROJECT
Tidelight_Production_Project.zip contains the updated Blender scene/source, raw public desktop capture, edit/capture scripts, narration/captions/music and production notes. The browser recorder uses Playwright screenshots streamed into FFmpeg. Reproducible Linux rendering requires FFmpeg, Blender, Python/Pillow, Playwright and Chromium. The final edit source is source/render_final.sh. The 3:54 edit keeps the recorded UI slow enough to read, using the original sampled screen capture, a 60 fps final timeline, and restrained chapter transitions. Captions use a 20 px ASS style with a compact translucent backing to stay legible over both light UI pages and dark cards.

The user confirmed the selected ElevenLabs voice is licensed for the intended submission.
