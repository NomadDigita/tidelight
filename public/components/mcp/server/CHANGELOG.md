# Changelog

This file records changes to the `@tidelight/mcp` package source.

## 0.1.0 — prepared, unpublished

- Added a local stdio bridge to Tidelight's hosted Streamable HTTP MCP service.
- Added strict API key and endpoint validation, scope-preserving discovery, and safe connection errors.
- Added package build, protocol and proxy tests, a CLI entry point, and package metadata.
- Kept registry publication disabled pending ownership, license, security-policy, and release approval.
